# **App Name**: DREAMER AI Portfolio

## Core Features:

- Real-time Portfolio Dashboard: Provide users with a consolidated, real-time view of their total balance, performance summary, and key financial metrics within a dark-themed interface.
- Personalized AI Insights: Generate and display tailored recommendations and strategic analysis using an AI tool based on the user's portfolio data and market conditions.
- AI Address Lookup Tool: Enable users to input an address (e.g., crypto wallet, public ledger ID) and receive AI-powered insights, verification, or relevant data linked to it.
- Dynamic Yield Performance Tracker: Visualize and display performance yields for individual assets or the overall portfolio with clear indicators for positive (emerald) and negative (rose) changes.
- Trust Score Display: Show a dynamically calculated 'Trust Score' (e.g., for assets, transactions, or overall portfolio health) within a visual circular component with color-coded feedback.
- Legacy Goal Monitoring: Track and visualize progress towards user-defined long-term financial 'Legacy Goals', providing status updates and achievements.

## Style Guidelines:

- Background Color: A very dark, subtle purplish-gray (#171319) providing a deep, sophisticated canvas.
- Primary Color: A confident and deep purple (#6638DB) for main interactive elements and branded components, suggesting insight and sophistication.
- Accent Color: A vibrant electric blue (#6272FF) used for highlighting call-to-action buttons, key data points, and secondary interactive elements, evoking technology and clarity.
- Data Visualization Colors: Utilize bright emerald green (#10B981) for positive performance, a vibrant rose red (#F43F5E) for negative performance, and warm yellow (#FACC15) for warnings or neutral states.
- Headlines: 'Space Grotesk' (sans-serif) for its modern, slightly techy feel, providing bold and clear titles.
- Body Text: 'Inter' (sans-serif) for high readability and a neutral, professional appearance in longer content blocks.
- Numeric Displays: 'Source Code Pro' (monospace) to render financial figures and code snippets with precision and alignment.
- Line-art icons: Use `lucide-react` icons (e.g., Sparkles, ArrowUpRight) throughout the application to maintain a clean, modern, and universally understood visual language.
- Modular Dashboard Layout: Implement a responsive grid-based structure with distinct, well-rounded cards and panels (`rounded-3xl`) for data and components, fostering clear separation and an intuitive hierarchy. Incorporate subtle gradient overlays within sections to add depth and visual interest on the dark background.
- Subtle Interactivity Feedback: Employ delicate animations like `animate-ping` for critical updates (e.g., trust score changes) and smooth transitions for state changes or content loading, providing elegant feedback without distraction.
